# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

We take the security of Pocket seriously. If you discover a security vulnerability, please do not open a public issue.

### Preferred Method
Please report vulnerabilities privately via [GitHub Private Vulnerability Reporting](https://github.com/kawaii-kitsune/pocket/security/advisories/new).

### What to Include
When reporting, please provide:
1. A description of the issue and its potential impact.
2. Step-by-step instructions or proof-of-concept to reproduce the behavior.
3. Your operating system and Pocket version.

### Response Timeline
- We will acknowledge receipt of your report within 48 hours.
- A fix will be developed, tested, and released as a patch release as quickly as possible.
